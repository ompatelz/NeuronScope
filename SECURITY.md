# Security policy

## Supported version

Security fixes target the latest revision on `main`.

## Reporting a vulnerability

Do not disclose a vulnerability, credential, or exploit payload in a public issue. Use GitHub's
private vulnerability-reporting option in the repository **Security** tab when it is available. If
private reporting is unavailable, open a minimal issue asking the maintainer for a private contact
channel without including vulnerability details.

NeuronScope intentionally accepts only bounded configuration for generated two-dimensional
datasets. Arbitrary model uploads, code execution, and real-world sensitive datasets are outside
the supported security boundary.
